# Amazon Sales Analytics | End-to-End Data Analysis Project

## Project Overview

This project presents an end-to-end analysis of an Amazon sales dataset using **Microsoft Excel, Python (Pandas), PostgreSQL, and Power BI**.

The objective was to explore sales performance, identify business trends, evaluate product and brand performance, analyze geographical markets, and develop business recommendations based on the findings.

The dataset contains **100,000 sales records** covering January 2020 through December 2024.

## Tools and Technologies

- **Microsoft Excel:** Initial data inspection and dataset review
- **Python (Pandas):** Exploratory data analysis and data quality checks
- **PostgreSQL:** SQL queries, aggregations, and business analysis
- **Power BI:** Data visualization and dashboard development
- **GitHub:** Project documentation and portfolio presentation

## Project Workflow

### 1. Data Exploration — Excel

Reviewed the dataset structure, columns, and sales records to understand the available information.

### 2. Exploratory Data Analysis — Python

Used Pandas to examine dataset dimensions, data types, descriptive statistics, missing values, and overall data quality.

### 3. SQL Analysis — PostgreSQL

Imported the dataset into PostgreSQL and performed SQL analysis covering:

- Total revenue, order count, and average order value
- Product and category performance
- Brand and seller performance
- Geographic revenue distribution
- Order statuses and payment methods
- Sales trends and data quality validation

### 4. Data Visualization — Power BI

Connected Power BI to PostgreSQL and developed report pages covering:

- Sales Overview
- Product Performance
- Geographic & Seller Analysis
- Sales Trends & Operations

Created KPI cards, revenue comparisons, product rankings, order analyses, and time-series visualizations.

**Important:** Recorded sales value includes orders with different fulfillment statuses and should not be interpreted as confirmed net realized revenue.

## Business Recommendations

1. Monitor high-performing product categories and identify opportunities for growth.
2. Use product sales rankings to support inventory planning.
3. Investigate expansion opportunities in existing international markets.
4. Analyze order returns and cancellations to improve operational performance.
5. Evaluate discount effectiveness across product categories.
6. Monitor seller and brand performance to support business decisions.

## Project Limitations

The dataset did not include complete product cost, profit margin, refund, or marketing expenditure information. Therefore, profitability and confirmed net revenue could not be fully evaluated.

## Conclusion

It strengthened my practical skills in Python, SQL, PostgreSQL, Power BI, and communicating analytical findings.

The completed project provides an example of using transactional data to support data-driven business decisions.
